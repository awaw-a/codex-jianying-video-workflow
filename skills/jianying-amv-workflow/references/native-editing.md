# Windows剪映原生操作

## 当前环境与副屏

执行UI前加载当前环境技能目录中的 `computer-use:computer-use`，从当前可用技能列表定位其真实安装位置。插件升级后重新发现，不依赖某台电脑或固定版本的路径。本资料不复制该skill的工具初始化、截图或点击协议；严格使用当次加载的API。

优先副屏，但必须先经当前允许的电脑工具确认窗口/屏幕可用性。缺副屏按实际环境工作并记录；不要猜显示器编号，不为布置画面擅自改全局显示设置。系统权限窗或用户必须处理的交互按当前computer-use规范处理，不能绕过。

## 先证明能力，再批量做

剪映版本、草稿格式、原生功能与缓存路径在环境里核对。新功能、升级后的兼容性、变速片段关键帧和不同媒体的图层顺序先在独立小样验证，成功后再批量装配。参数被写入JSON并不证明播放器或导出中生效。

已有案例在特定剪映版本中验证过legacy明文新工程可读、旧mask字段不生效、自由层级须补正确索引、部分公共关键帧按原素材时钟解释。这些是回归测试线索，不是所有版本的保证。原生加密保存后保留完整工程，不尝试解密或改写旧用户草稿。

小样应覆盖当前任务最脆弱的组合：非零源入点、变速、文字字体、文字/视频跨类型层级、蒙版与抠像缓存、工程保存重开、实际导出。只验证将要使用的能力，不机械制作功能展览。

## 时钟与同步层

识别每类关键帧使用源clock还是target clock，再转换一次。若经验证采用源clock，固定速度时为 `source_in + target_offset * speed`；分段速度累计转换。不能给已转换的数据再次乘speed。检查首/中/末可见落点，不只查JSON末键。

人物前景由主镜头同步副本得到。源范围、速度、位置、比例和路径保持一致；只改变需要的图层关系或背景窗口。同一前景不能同时留下两个人物实体。继承基底动画时重新生成对象标识，避免两轨共享可变关键帧id。

抠像按profile要求使用原生功能。剪映智能抠像/智能画笔处理后保存可编辑设置及完整缓存，检查手指、细武器、头发、腿间孔洞和光效粘边。缓存数量与大小正常不代表轮廓质量通过；用实际合成画面检查。失败时更换镜头、调整设计或修原生轮廓，不能偷偷用外部matte满足“原生”交付。

## 保存、调整与停止线

修改前完成可恢复备份；主agent是唯一UI/工程写入者。需要改同一句分层字幕时同步前/SPACE/后三段位置，检查原有位置关键帧是否覆盖UI静态值。改变速度、裁剪、图层或终点后，重验受影响证据。

完成阶段修改后保存关闭、完整备份，重开工程验证引用与实际长度。保留原生缓存、字体依赖与媒体登记。画面、前景、背景、字幕及音轨停止线按设计统一，不能靠定格或黑尾掩盖映射错误。用户需要可继续编辑的主要效果，不仅是一份渲染视频。
