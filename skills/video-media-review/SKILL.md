# 视频独立审查

先读项目状态、个人约束及当前被审对象的身份。接受明确审查范围；用户要求“评审”时只给证据和建议，不擅自重剪。主工程/UI由主agent唯一写入；本skill只写分配的独立审核目录。

状态与字段约定见 [项目契约](../jianying-amv-workflow/references/project-contract.md)。执行统一 `video_workflow.py` 时先看当前help，不复制另一个审查工具实现。

- 检查素材、时钟、实际导出像素和声音：按需读 [export-review.md](references/export-review.md)。参数检查、实际视觉、数值音频与真实听审分别记录，不合并成含糊的“全通过”。
- 检查保存、依赖与跨电脑交付：读 [handover.md](references/handover.md)。可编辑主效果、原生缓存和迁移重连要验证。

发现问题时报告具体对象、帧/时间、可见或可测证据、影响及最小修正。区分必须修复与创作取舍，不能把技法数量或编码正常当作观感好。修正后只重验受影响范围；新导出身份变化时重新绑定证据，不能无条件沿用旧结果。

未经真实听审，明确待用户听审；ASR、静音检测、响度、相关性和无削波不能成为用户听审确认。审查者提出阶段建议，项目状态由主agent统一更新。
