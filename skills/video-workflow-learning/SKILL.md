# 视频复盘与升级提案

读取当前项目状态、相关审核证据和唯一profile。按 [learning-proposal.md](references/learning-proposal.md) 记录经验，区分新增需求、实现缺陷、创作取舍和环境差异；不把所有返工都归为错误。

重要经验及时提出窄范围升级。先保存可追溯候选，再说明影响、适用边界和拟改位置；用户接受前不更改长期规则或已发布skill。项目内已授权修复照常完成，不需要为记录经验停工。

将跨项目通用方法、动漫/游戏剪辑方法、个人偏好、单作品参数分层。固定帧率、拍速、字号或本片台词不能成为通用模板值。不要通过累积大量重复规则形成第二个profile。

复盘不修改原视频、原生工程/UI，也不回填未做过的听审或实像通过。用户要求实际升级时，在指定范围做可审查修改并验证；保持自动发现策略，除非用户明确更改它。
