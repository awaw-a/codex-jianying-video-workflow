# Agent 实操

适用 Windows 剪映中的动漫／游戏音乐剪辑。制作与接手使用 [jianying-amv-workflow](../skills/jianying-amv-workflow/SKILL.md)，独立审核使用 [video-media-review](../skills/video-media-review/SKILL.md)，复盘使用 [video-workflow-learning](../skills/video-workflow-learning/SKILL.md)。版本操作细节分别在 skill 的 references 中，不能用本文替代本机验证。

## 入口、职责和项目事实

先读项目 `AGENTS.md`，再读其中指定的唯一状态文件、当前 profile、使用素材台账和最近审核。核对当前原生工程是否已被剪映保存、导出是否与其对应。不要通过“文件名带终版”判断权威，也不要把历史 EDL 的结尾或旧 prepared JSON 当作当前事实。

主 agent 是原生工程和剪映 UI 的唯一写入者。可按需委派音乐／参考研究、源镜头查找、只读数据检查与独立实像审核；委派时给出允许读写目录、输入版本、禁改范围和返回条件。协作者的新素材与审核结果进入自己的输出目录，只有主 agent 决定怎样装配和更新状态。

项目 `AGENTS.md` 保持短小，长期偏好只引用 profile。状态记录事实和下一动作，素材台账记录来源与使用，审核记录证据。接手页由状态生成；不能再手写一份不同进度的“最新版说明”。

## 从需求到完整初版

| 阶段 | 必须形成的可检查结果 | 推进条件 |
| --- | --- | --- |
| 环境与素材 | 实际剪映安装／草稿目录、运行时、显示器与可用工具；原片索引、帧率／音轨／字幕信息 | 关键工具可用；缺项有明确影响与可选方案 |
| 多轮讨论 | 情绪、人物主线、乐句结构、完整脚本；项目例外与资源限制 | 已有具体、可制作的完整设计 |
| 源媒体 | 安全镜头区间、原声完整区间、使用台账、跨母版重复候选 | 全部实际使用源区间加余量已看；不靠稀疏抽帧推断整个镜头 |
| 功能探索 | 版本与功能对应的小样、实际可见证据 | 关键效果在本机可见；失败时改方案或记录限制 |
| 装配与原生制作 | 新工程／版本、完整时间线、原生抠像完成记录 | 音画与层级同位；当前原生保存有效 |
| 导出检查 | 解码／边界／实际效果／歌词／声音证据分别记录 | 明显问题已修；未验证项准确列出 |
| 用户完整初版 | 完整视频与少量重要限制 | 不将碎片小样替代初版 |
| 修订与定稿 | 完整修订版、用户真实听审结论、最终完整备份 | 未真实听审不得定稿 |

发现新的可执行用户反馈应继续修订。若只需要常规实现选择，agent 自行判断；新增付费、账号或上传原片才使用对应确认边界。

## 源镜头、变速与有意重放

记录 source 身份、canonical scene、原片入出、代理入出、实际帧率、目标入出与 occurrence。区间统一为起点包含、终点不包含。代理帧数、PTS 和最后一帧应实际解码确认；编码器声明“24fps”不能代替检查。不同集或母版可能引用同一个回忆画面，路径不同也会重复。

同一个动作可由若干连续单向变速子段组成，源区间顺接且不重叠时属于一次播放。前景与背景必须同源时刻、同位置、同缩放；它们合成一次画面，不是第二次播放。不同步或缩放不一致会形成双人物，不能套用“同位例外”掩盖问题。

个人规则允许有意定格、倒放和节奏重放。使用前在台账声明 effect_type、creative_purpose、source_identity 和 target_interval；审核区分声明过的设计与无意复用。不能为了填时长偷偷冻结或回放原画。

## 关键帧、蒙版和交接

在当前剪映版本做微型小样，分别验证原生蒙版、宽／高关键帧、自由层级、原生抠像和字体；字段写入成功不等于 UI 生效。版本库记录“在哪个版本、什么组合、看到了什么”，不要把某次 resource ID、窗口坐标或固定路径做成通用常量。

若本机原生视频／音频关键帧以源时钟保存，转换式为：

`source_time = source_start + local_target_time × speed`

连续变速逐段映射，不能用整段平均速度。字幕或其他无 source_timerange 对象的时钟需另外验证。保存映射表并通过小样／实际导出确认，不仅检查 JSON。中心偏移、旋转后的蒙版“full”必须真实覆盖全画幅，不能只把宽高写成 1.0。

人物交接至少核查五个阶段：新底图先出现，旧前景保留；新前景开始可见；旧人物平滑退出；新窄背景有可感知的保持；新背景最终展开。旧前景延伸使用连续、独占、安全的源尾，不复制最后帧凑长度。新增前景单独轨道避免与旧人物抢层级。

原生抠像应在 UI 完成必要修补并 Apply。查看头发、脸、双臂、腿间隙、武器与背景残留的运动变化；不能只看首尾。保留当前草稿及原生缓存，旧生成脚本不得覆盖后来保存的结果。

## 歌词与原声

非默认字体记录文件和许可。主歌词／空间歌词分层时，句子的 before、SPACE、after 各段应位置、样式和字数一致。检查关键动词、低置信词、最右标点、亮底描边、脸和打击落点，不以“字体路径已写入”证明可读。人物可遮部分字，但不应把整句意义藏掉。

台词源区间应结合字幕、ASR、波形／静音和上下文选取，保留整句音节及尾余量。音效检验击打接触、余响和后续另一声音；原作配乐混入要说明。允许降噪、EQ、适度压缩或必要分离，但处理后重新检查。当前偏好不使用局部 BGM ducking；优先选更干净的原声并调整它自身。

不能真实耳听时，不宣称听感、歌词词义或尾音已通过。用户真实听审前保持待定稿。最终停止点需要音画一起核对；视频流与 AAC 尾部的微小时长差异先辨别编码填充，不能直接当作时间线错误。

## 工具入口与证据

工具是 [toolkit/video_workflow.py](../toolkit/video_workflow.py)，先读取其 `--help` 和子命令帮助。`probe` 检查实际媒体，`audit-usage` 检查使用台账，`map-clock` 做明确时钟转换，`audit-export` 检查导出，`validate-state` 核对状态，`handoff` 生成接手资料，`pack-project` 打包，`invalidate-evidence` 标记因修改失效的证据。它们不自动操作剪映，也不代表已经实际听审。

只读审查优先使用 `--no-write`；需要落盘的报告写新审核目录，禁止调用会重写 EDL 的旧审核脚本。每份结果绑定输入文件指纹、版本、实际检查区间、工具／人工动作与限制。修改素材、变速、效果或导出后，应明确哪些证据需要重做，避免拿旧报告为新视频背书。

以下命令的接口已按本包实际 `--help` 核对；运行前定位可用 Python，将示例项目路径换成真实路径。它们是工具用法，不代表已完成项目验收。

```powershell
# 从文件包根目录运行；python需对应本机已验证的Python运行时
python ".\安装与初始化.py" install
python ".\安装与初始化.py" init-project --dest "D:\新项目目录"

# 只读核对状态与依赖，不生成审核文件或启动剪映
python ".\toolkit\video_workflow.py" validate-state --state "D:\新项目目录\PROJECT_STATE.json" --no-write
python ".\toolkit\video_workflow.py" audit-usage --state "D:\新项目目录\PROJECT_STATE.json" --no-write
python ".\toolkit\video_workflow.py" handoff --state "D:\新项目目录\PROJECT_STATE.json" --no-write
python ".\toolkit\video_workflow.py" pack-project --state "D:\新项目目录\PROJECT_STATE.json" --no-write
```

安装到另一机器用户目录可为 `install --home "实际用户目录"`；新项目初始化也支持 `--home`。实际打包使用 `--out "新的打包目录"`；已有目标默认拒绝。媒体探测与导出审核需先看各自帮助，提供实际 FFprobe／FFmpeg 与当前项目的帧率、停止点，不能套用本案例的数值。

可复用工具与历史一次性脚本的取舍见 [复盘](../examples/越过高塔/复盘.md)。备份、陈旧 UI、技能发现和失败恢复见 [故障与证据](故障与证据.md)。
