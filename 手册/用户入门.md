# 用户入门

从 [开始使用](../开始使用.md) 进入。长期偏好以 [user-profile.json](../data/user-profile.json) 为准；本手册解释怎么合作，不承担项目进度记录。

## 你需要提供什么

新项目先提供原片和音乐位置、期望的观看场景，以及最在意的情绪或人物。现有参考可以是公开链接、视频或截图。没有剪辑思路也可以开始讨论；此时 Codex 应先检查素材与音乐，提出几种具体方向供你选。

如果提供的是游戏录像，还应说清楚精彩事件、视角切换、界面是否需要保留。画幅、时长、分辨率和帧率应为这个项目单独确定，不能沿用前一个作品的数字。

## 讨论和制作怎样分开

每个新项目先进行多轮讨论。建议顺序是：想让观众感受到什么；哪些人物或事件构成主线；音乐哪些段落承担铺垫、爆发和结束；再谈字幕、空间效果和转场。Codex 需要把参考里的具体手法转译成现有素材可实现的镜头，而不是照搬每个特效名称。

进入制作前，你能看到一份完整脚本：每段用途、主要画面、音乐落点、歌词／原声和关键效果。脚本中的未知素材应明确标记，不能用不存在的镜头伪装成已确定方案。

制作阶段你主要看完整初版和完整修订版。agent 应自行发现并修复明显的重复、串景、坏帧、文字越界、错位和失效效果。工具探索与小样由 agent 验证，只有需要你补充材料、处理账号权限或作重要创作选择时才打断你。正常进度说明不需要你逐个批准。

## 已确认的创作偏好

| 偏好 | 实际含义 |
| --- | --- |
| 主要效果原生可编辑 | 在剪映中能继续调蒙版、字幕、变速和层级。外部生成素材保留来源与替换方法。 |
| 原生人物抠像 | 使用剪映内置抠像与必要的原生修补；实际导出中检查头发、双臂、腿、刀锋和背景残留。 |
| 字体与歌词 | 选有许可的非默认字体；歌词无全宽底栏，入场方式有变化；允许人物遮部分字，关键意思仍需可读。 |
| 出框与人物交接 | 窄背景有可感知的停留；交接按“先换背景—旧人物继续—新人物出现—旧人物退—新背景展开”。保持时间随素材与乐句设计。 |
| 音乐与原声 | 卡点重要，多用有作用的台词和音效；不通过局部压低 BGM 处理原声。可调整原声、清理噪声或适度分离原作配乐。 |
| 重复规则 | 禁止无意复用；有目的的定格、倒放、重放、loop 可以用，设计须声明来源、区间与目的。 |
| 结尾 | 与音乐结束建立明确关系，不拖无意义尾巴；需要听审确认停止感。 |

这些是当前个人 profile 的偏好。你对某个新项目的明确例外优先，agent 应把例外写入该项目，避免误改所有后续作品的规则。

## 怎样给出有用的反馈

一次反馈可以包含“时间＋画面＋感受＋目标”。例如：

> 28秒五条举手这段有空间感，保留；但旧人物消失太快。我想新背景先出现，等虎杖进入后五条再退。不要重复播五条原画来凑时长。

> 86秒我看不清 legacy，而且挡住敌人脸；我想文字沿刀轨退开，动作落点仍保持。

> 76秒台词感觉尾巴少了一点，请保留整句再试听；不要只按字幕结束时间截。

这比“再炫一点”更容易落实。你也可以只说明不喜欢的地方；agent 应结合实像提出方案，不要求你掌握关键帧、材质 ID 或源时钟。

反馈可能是已存在的技术缺陷，也可能是你后来发现更想要的审美方向。两者都应处理，但复盘要区别来源。例如，《越过高塔》的无意重播与镜头串景属于缺陷；后来提出更长出框停留和两人物交接，是新的具体设计要求。

## 听审怎么做

用实际交付版本，正常音量完整听一遍，再重复下面几类位置：音乐拼接处、每句重要原声的头尾、最强打击、歌词低置信词和结束点。记录“在哪个版本、哪个时间、听到了什么”。不要仅凭联系图或静音预览确认声音。

重点判断台词是否完整、打击余响是否突断、原作配乐是否混入过多、音乐是否明显被切坏、声音是否过载，以及最后画面停止与音乐衰减是否舒服。数值无削波只能说明技术指标；它不等于听感好。

> 我已经完整听过「具体导出文件名」，音乐拼接、原声头尾和结束点通过；歌词的某某词需改。修好这一项后再给我最终版。

如果没有真实听过，直接说“还没听审”。agent 必须保留待听审状态，不替你确认。

## 怎样接着做或换电脑

接手已有作品时，发送项目目录并要求从 `AGENTS.md` 和状态入口继续，不要让 agent 从历史脚本重新生成主工程。移机按 [接手与迁移](接手与迁移.md) 做；先看移机检查结果，再在新机继续制作。

公开素材与已接通的生成工具可自主使用，但来源与许可要记录。新增付费服务、开新账号或把原片上传到外部服务，需要另行说明并确认。
